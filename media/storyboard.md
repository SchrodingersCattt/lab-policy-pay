# Ledger Lab — demo storyboard

Target length: 100–140 seconds. Use the English narration and show real actions.

1. Show a synthetic policy notice and extract the three rules using the model.
2. Review the quoted evidence, edit if necessary, and confirm the policy.
3. Submit one request within the limits and one that is blocked.
4. Approve the eligible request, complete a sandbox purchase and show the ledger.
5. If Payouts is enabled, show a sandbox reimbursement and its actual item
   status. Otherwise explain that reimbursement payment is not enabled.

Do not publish credentials, personal data, or an unverified payment result.
